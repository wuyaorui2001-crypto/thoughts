| **两端缩进 (Margins)**     | 16             | 两边留白，能像实体书一样把视线聚焦在屏幕中央。              |
| **段前/段后距**             | **16px**       | 建议段落之间不只是敲回车，设置段后距会让间距更均匀。           |
| **文字颜色**               | **#333333**    | 接近纯黑但更柔和，适合长时间盯着屏幕。                  |
| **背景颜色**               | **#FFFFFF**    | 纯白背景是永恒的经典，最衬文字。                     |

## 个人网站（PersonWebsite）

上面是**公众号**用的。网站单独一套：电脑屏幕更宽，所以栏宽、字号、背景和公众号不一样。

改文章文字：改 `Article/EP xxx.md`。  
改网站好不好看：改 PersonWebsite 的 CSS，**不要**为了排版去改原文。

| 项目 | 网站怎么做 | 说明 |
|------|------------|------|
| **正文字号** | 约 17px（`1.0625rem`） | 屏幕比微信编辑区大，15px 会显瘦 |
| **行高** | 1.75 | 和上面公众号一样 |
| **字距** | `0.02em` | 对应上面的 1px 字距 |
| **阅读栏宽** | 约 **65ch** | 一行不要太长；只限文章详情，**简历不收窄** |
| **对齐** | 左对齐，和顶栏导航齐平 | |
| **正文颜色** | `#2e2a26` | 暖黑，接近上面的 #333 |
| **页背景** | `#f6f2eb` | 暖纸色；网站不是纯白，这是有意的 |
| **段后距** | 约 15px | 接近上面的 16px |
| **分节数字** | 单独成行的 `1` `2` → 三级标题；约 18px；段前约 28px、段后约 10px；第一节贴着文题 | 构建时自动转，原文不用写成 `### 1` |
| **分节线** | `----` → 短、居中、细线 | 不要通栏粗线 |
| **标题换行** | `text-wrap: balance` | 少出现标题最后剩一个字 |
| **正文换行** | `text-wrap: pretty` | 少出现段尾孤字 |
| **金句 / 长引文** | 原文用 `>` | 网站才会加左边线 |
